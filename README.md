## Como experimentar

1. Abra a demonstração de um modelo e explore suas seleções, filtros, menus ou formulários locais.
2. Use **Reiniciar demonstração** para voltar ao cenário inicial.
3. Abra o código, consulte os critérios de aceite e siga o README para rodar localmente. Node.js 22.12+ e npm são os únicos requisitos de aplicação.
4. Para uma edição própria, substitua marca, conteúdo e ativos, preserve licenças e adapte as regras da interface.

Os modelos são **conceitos fictícios**, com dados e valores ilustrativos. Não representam clientes, resultados comerciais ou sistemas de produção. Não há pagamento, login, agenda real, backend ou envio de formulários. O estado da demonstração é perdido ao recarregar.

## Código e origem verificáveis

A coleção corresponde aos 17 conceitos setoriais de [Modelos LOFRANO](https://lofranotecnologia.com.br/modelos). As 6 aplicações interativas de outra área do site são um conjunto separado. O backend e a operação privada do site não fazem parte desta entrega.

Os componentes foram recuperados dos artefatos públicos de cliente com análise estática REA e transformação por AST, incluindo dependências lexicais, nomes descritivos de estado e JSX legível. A edição independente adapta caminhos de assets, moldura e reinício; não é uma exportação do TypeScript original. Cada projeto contém `docs/ORIGEM.json` com fonte e hashes.

A validação compara o conteúdo inicial completo com o HTML público, testa fluxos em JSDOM e constrói o cliente em namespace isolado, com fonte/dependências somente leitura, sem rede, home ou credenciais. JSDOM é DOM simulado: não equivale a QA visual em navegador. O controle oficial de navegador estava indisponível durante esta preparação; não foram fabricadas capturas.

## Organização e nomes

O padrão `lofrano-<marca>-<finalidade>` identifica autoria e assunto, com URLs ASCII e títulos em português. Cada modelo tem finalidade e identidade próprias. `catalogo.json` fornece os links em formato legível por máquina.
